Setup

Guidelines — getting started

1. Install & run +
Extract the ZIP you receive on Telegram and double-click ZYRA.exe. First launch can take a few seconds — that's normal.
2. Add your free Gemini API key +
Get a free key at aistudio.google.com/app/apikey and paste it into ZYRA's API setup screen on first run. This key is yours — we never see it.
3. Enter your activation key +
If you bought the key or bundle, paste your activation key when prompted. It unlocks on this device only.
4. Use headphones +
For the smoothest conversations, use headphones instead of speakers — it stops ZYRA from hearing her own voice through the mic.
5. Allow mic & camera access +
Windows will ask for microphone (and camera, if used) permission the first time — allow it so ZYRA can hear and see you.
